# Python Courses Projects

This repository contains two main projects: **Project1** and **Project2**.

## Project1
- **Files:**
  - `error_handle.py`: Handles errors in the project.
  - `youtube.txt`: Contains data or configuration for YouTube management.
  - `youtube_manager.py`: Main script for managing YouTube-related tasks.

## Project2
- **Files:**
  - `youtube_manager.db`: Database file for storing YouTube management data.
  - `youtube_manager.py`: Main script for managing YouTube-related tasks.

## Getting Started

### Prerequisites
- Python 3.x installed
- (Optional) Create a virtual environment for project isolation

### Setup
1. Clone the repository:
   ```powershell
   git clone <your-repo-url>
   cd Python_Courses
   ```
2. (Optional) Create and activate a virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   ```
3. Install required packages (if any):
   ```powershell
   pip install -r requirements.txt
   ```

## Usage
- Run scripts in `Project1` or `Project2` as needed:
  ```powershell
  python Project1\youtube_manager.py
  python Project2\youtube_manager.py
  ```
